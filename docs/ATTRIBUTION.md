# Attribution and source boundaries

This is an independent reference-based reconstruction of the BETAFPV Air65 II Racing. Product and component names identify the objects studied; they do not imply manufacturer endorsement.

The research sources and reference-image provenance are recorded in `research/`, `specs/design_spec.json` and `references/*.json`. No open redistribution licence was established for the downloaded manufacturer/reviewer photographs. Those image files and the older photo-containing comparison sheet are excluded from the GitHub repository and public release archives. Consult the original source links for the reference imagery.

The model's five PNG textures are authored artwork produced by this project's scripts, not projections of the reference photographs. Typeface, micro-layout, packaging motifs and optical properties include the documented estimates. Original screenshots and renders are included as evaluation evidence.

Three.js 0.186.1 and the included addons retain their MIT licence at `site/dist/vendor/three/LICENSE`. That licence applies to the vendored Three.js code; it is not a blanket licence for third-party research images or all project assets. No additional project-wide reuse licence has been selected in this publication.
